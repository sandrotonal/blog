React Server Components (RSC), React ekosistemindeki en büyük mimari değişikliklerden biri.

## RSC Neden Var?

Modern web uygulamalarında JavaScript paketi gittikçe büyüyor. RSC bu yükü sunucuya kaydırarak tarayıcının daha az iş yapmasını sağlar.

## Avantajları

- Daha hızlı ilk yükleme (LCP)
- Daha küçük bundle size
- Doğrudan backend erişimi (veritabanı sorguları vb.)

## Sonuç

React artık sadece bir "UI kütüphanesi" değil, tam kapsamlı bir uygulama mimarisi haline geldi.
